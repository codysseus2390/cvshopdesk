# Figma plugins for ShopDesk

Resources → Plugins → search these names. Skip everything else until you feel a real gap.

Brand tokens to keep in Figma Variables:
- Oil black `#0B0B0C`
- Warm paper `#F3EEE6`
- Cedar flame `#F2581A`
- Stone muted `#9C968C`

## Install

1. **Tokens Studio for Figma** — colors, spacing, type as tokens; export JSON later.
2. **Stark** — contrast on cedar-on-black and paper-on-black; touch targets for shop-floor phones.
3. **Iconify** — pick one set (Lucide or Phosphor) and stay on it.
4. **Content Reel** — fake customers, phones, tire sizes, RO numbers.
5. **Unsplash** — vehicle / shop photos for empty states and OG mocks.
6. **Rename It** — batch-rename layers before handoff.
7. **Table Creator** — work-order and inventory tables without fighting Auto Layout.

Optional later: **LottieFiles** (if you add motion on the booking page).

Do not install five AI “generate the whole app” plugins.
